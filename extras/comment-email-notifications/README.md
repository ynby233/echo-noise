# 互动邮件通知（封存外挂）

状态：**封存，未上线，不受支持**。

这里保存的是原项目“评论、回复、留言邮件通知”模块的历史实现快照，便于未来重新设计时参考。目录位于运行时源码树之外，源码使用 `.disabled` 后缀：

- 不参与 Go、Nuxt、Docker、桌面端或移动端编译；
- 不会进入服务端、桌面端或移动端构建产物；
- 不注册路由、不创建数据库字段、不显示管理面板，也不会发送互动邮件；
- 不能通过改名或复制回运行时目录直接启用。

封存内容包括原 `CommentsSettings.vue` 配置与预览组件、原 `PostComment` 邮件投递源码片段，以及对历史字段和行为的说明。它们保留原实现仅供审计和重新设计参考，不是可直接启用的插件。

当前仍继续可用的是内置评论、回复、留言、互动回收站、站内通知以及其他独立的 SMTP 用途。站内通知不依赖本封存模块。

## 封存原因

历史模块存在以下未完成事项：配置面板与后端字段未完整接线、旧“仅登录”开关已被账号强制登录模型取代、管理收件地址复用了 SMTP 发件地址、HTML 内容未进行安全模板转义、SMTP 投递同步且缺少超时/队列/失败状态，亦无完整自动化测试。

## 未来恢复条件

后续版本必须重新设计后再上线，至少完成：

1. 独立的扩展接口与显式启用机制，默认不装载；
2. 独立、可迁移且可回滚的配置模型；
3. 管理收件人与用户回复收件人的明确规则；
4. 安全的文本/HTML 模板渲染与变量定义；
5. 带超时、队列、重试和可审计状态的异步投递；
6. 可见性缩窄、自回复、未验证邮箱和祖先链场景测试；
7. 模拟 SMTP 端到端测试以及服务端、桌面端、移动端验收；
8. 单独的权限能力和“无权限不显示、后端拒绝”双层约束。

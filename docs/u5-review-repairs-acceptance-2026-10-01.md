# U5 独立复核问题修复与验收

日期：2026-10-01。修复起点 `a35ac04601a4a2e69f042963ca76169ccdf6193c`。用户明确要求修复复核中所有问题、提交推送并自行核验；不安装 NAS 执行器、不替换业务容器、不发布正式 Release。

## 已修复行为

1. 任务创建的 HTTP 409/412 等明确拒绝保留状态及服务端原因。页面显示拒绝原因，允许重新检查、确认，不再永久显示创建结果不明。网络断线/服务异常仍只查询、不自动重发 POST。
2. 发起创建前记录已知任务 ID；响应丢失后，同一条旧 succeeded/failed 任务不能解除不确定状态。新的任务或真实活动任务才恢复跟踪。真实生产 Vue/Chromium 回归保留旧失败任务，模拟请求已送达但尚未创建，查询旧结果仍禁安装，原请求随后创建新任务后自动恢复，POST 数量不变。
3. 部署预检的 OSError/ValueError/KeyError 与既有 Stop 都尽力上报 ok=false。非有限异常转换为 deployment_check_failed，路径和原异常内容不进入公开输出。实际删除登记备份目录使 check_space 抛 FileNotFoundError：先前成功后上报失败，不 claim、不建 journal。
4. 首页原懒加载回归的“留言按钮在 viewport 外”已定位为既有工具栏避让收起。脚本通过可见的 sidebar-avoidance-handle 正常点击展开，再点击留言；未强制点击、未放宽加载/错误/草稿断言，未改产品首页布局。完整首页回归现在通过。

# R5：编辑器、渲染器与后端职责拆分

本次范围来自桌面交接报告第 9 节，对照版本为 `ce8267ee`。目标是把原有实现放到明确的职责和生命周期中，保持编辑内容、正文展示及后端数据行为。未改路由、账户权限、数据库结构、Markdown 引擎、网络架构或 Android/MCP 功能。

## 实现

| 原入口 | 当前职责 |
| --- | --- |
| `internal/controllers/controllers.go` | 原函数迁到同包的认证、笔记查询/变更、评论、版本、设置、状态、用户、友链、媒体等文件；导出名及路由调用保持。原文件移除。 |
| `internal/services/setting_service.go` | 拆为前端配置读取/保存、访客设置、小组件、RSS、登录有效期、公告广告、VoceChat、默认配置等文件。原文件移除。 |
| `internal/services/feed_service.go` | 拆为调度、加载/缓存、各数据源、JSON/XML/配置解析、内容处理及类型文件。原文件移除。 |
| `VditorEditor.vue` | 保留模板、样式、Vditor 配置、主题与组件生命周期编排；实例、工具栏、DOM 输入会话和表格拖动由独立模块负责。 |
| `editor-dom-session.ts` | 集中维护输入、选区、组合输入、附件、表格单元格和序列化状态；提供 `mount/update/dispose`、编辑 API 及模板控制项。调用方不共享内部选区状态。 |
| `MarkdownRenderer.vue` | 保留预览流程编排；媒体布局、附件增强、表格展开、表格增强及任务状态移到独立模块，复用原有预览和媒体工具。 |
| `MessageList.vue` | 保留列表、权限、分页与交互编排；编辑弹窗、媒体、内容测量、点赞/评论状态、定位和菜单分别管理。保持 keyed identity、懒渲染及现有布局方式。 |

拆分过程中删除被替代的原实现，没有引入新的数据访问转发层、虚拟列表、通用事件框架或行数门槛。

## 生命周期与回归修正

- 工具栏同时支持容器本身就是 `.vditor` 的实际 DOM；观察器帧、重试任务和祖先滚动监听由工具栏模块释放。
- Vditor 生命周期覆盖异步/同步 ready、重复 ready、销毁后迟到回调及重新挂载。
- DOM 输入会话统一释放监听器、观察器、计时器、动画帧及附件预览代理。独立测试先复现“表格输入排队后立即销毁仍向旧父组件回写”，再验证修复后无迟到回写。
- 表格拖动继续使用原尺寸计算工具，针对当前实例的表格引用操作；销毁停止拖动而不再排队布局任务。
- 编辑上传和消息定位异步结果检查当前操作，销毁时取消并结束等待任务，防止旧结果覆盖新编辑/新定位。

后端原有 115 个控制器函数、136 个服务函数按 Go AST 比较，251 个函数实现一致，无丢失。此项核对用于解释机械迁移，不替代运行测试。

本地检查：

- 前端全套 114 个测试文件通过，包含可直接导入的 DOM session、Vditor lifecycle、表格拖动、任务更新、编辑异步和定位竞态测试。
- `nuxi typecheck` 通过。
- NAS 服务端涉及的 Go 包测试通过；`mobilebackend` 按本次明确范围排除，不能把此结果描述为 Android 验收通过。
- `git diff --cached --check` 通过。
- 停止开发服务、`nuxi cleanup` 后执行静态生成。此前开发/生产生成目录同时使用时出现过 Nitro `file:///_entry.js` 错误，清理后成功生成 9 个页面与 PWA；未修改构建配置来绕过错误。

本地 Chrome 中使用隔离挂载样例，不保存或发布笔记：

- 当前版与 HEAD 原版在中文、连续空行、任务列表、附件表格、200 段长笔记五组输入上的编辑器输出逐字一致。
- 原生组合输入在稳定选区正确产生中文文本；执行了连续输入、撤销/重做、任务回车及多行粘贴。任务回车形成下一条待办。
- 最终版五次挂载/销毁、亮暗交替均成功；每次销毁后测试容器无残余节点。检查的 resize、scroll、beforeinput、paste、selectionchange 监听器数量恢复至挂载前水平。
- 最终版表格列宽从 905.3px 拖到 950.3px，正文内容不变，释放后拖动状态清空。展开关闭后无残留对话框。
- DOM session 的迟到回写、表格缩放的最小尺寸/缩放比例/小数坐标/取消清理、编辑上传和通知定位的旧请求处理均有可执行测试。

这些是本地结构与行为验证，不是 NAS/iOS 真机、真实上传音视频播放或线上部署验收；没有据此声称输入性能提升。临时原版对照组件及隔离浏览器挂载均已清理。推送及镜像工作流结果在交付消息中单独记录。

# 后台界面样式

后台使用 `web/assets/css/admin.css` 和 `AdminModuleHeader.vue` 统一展示。样式作用于后台根节点及后台弹窗，不改变首页、登录页的字体和布局。

## 页面与控件

| 元素 | 约定 |
| --- | --- |
| 页面标题 | `AdminModuleHeader`：16px 标题、12px 说明、32px 图标底框，图标与导航对应；操作放入 `actions` 插槽 |
| 主卡片 | `admin-card`：8px 圆角、1px 边框、轻阴影 |
| 内部配置卡片 | `admin-subcard`：12px 内边距、8px 圆角、主题浅底色，无悬浮阴影 |
| 间距 | 页面内部默认 16px，配置组之间 12px；窄屏内边距 12px |
| 按钮 | `admin-action`：桌面最小高度 36px，窄屏最小高度 40px；统一字重、图标尺寸和焦点样式 |
| 单行字段 | `admin-input` / `admin-select`：36px 高；原生日期框使用 `admin-field` |
| 多行字段 | `admin-textarea`：由字段的 `rows` 决定初始高度，允许纵向调整；不设全局 120px 最小高度 |
| 状态标签 | `admin-badge`：12px 字号、4px 圆角，按状态保留语义颜色 |
| 弹窗内容 | `admin-dialog`：复用后台字体、按钮与表单样式；传送到页面根部后也能生效 |

保存、创建等主要操作使用 `primary`；刷新、重置、取消及翻页使用 `gray`；移入回收站等需注意的操作保留橙色，永久删除等危险操作保留红色。成功、失败和禁用状态继续使用各自的语义提示。

欢迎语、PWA 简短描述及 URL 使用单行输入框；个人签名、公告、Markdown 正文保留多行。不要通过固定卡片高度或拉伸字段来对齐不同长度的表单。

## 布局与主题

保留现有五种后台配色。主题颜色通过 `--admin-*` 变量提供；配置卡片、字段、图标与按钮从同一套变量取值。导航选中项使用主题强调色，后台字体统一为系统无衬线字体。

窄屏标题与操作区分行，操作允许换行。`admin-settings-toolbar` 用于配置子卡片的标题和按钮组合。大型数据表保留局部横向滚动，避免整页被表格撑宽；个人内容保留响应式卡片列表。

这次调整覆盖后台全部 35 个导航模块，包括个人内容、站点展示、互动管理、权限审计、存储维护及各自弹窗。权限判断、API、数据修改与删除确认流程仍由原组件负责。
